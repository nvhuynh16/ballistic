# Trap census

Every way this library has been found to give a plausible but wrong answer,
or to let a user get one, is listed here once. A trap is **closed** only when:

- the instances are fixed;
- a guard exists that fails if the trap comes back (a unit test, a static
  rule in `tests/python/test_static_guards.py`, or a check that refuses bad
  input at run time).

An open trap names its planned fix in the last column.
`tests/python/test_trap_census.py` checks:

- every closed row names a guard that exists;
- every open row names the planned fix;
- every static rule appears here.

Guard formats:
- `tests/<path>` — the test file;
- `tests/<path>::<name>` — a named test or cell in that file;
- `static:<RULE-ID>` — a rule in `test_static_guards.py`.
