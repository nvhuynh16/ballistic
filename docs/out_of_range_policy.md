# Out-of-Range Policy by Data Table

Every time- or altitude-indexed data table in the library has its own policy
for queries outside its domain. They differ, and this table is the single
place that documents the edge behavior.

| Table | Out-of-range behavior | Signal to the caller |
|---|---|---|
| **EOP** (`time::EOPData`, finals2000A) | One lookup (`EOPData::lookup`) serves every consumer: the IAU transforms, `Epoch` UT1, the TEME conversion of SGP4 states and `Trajectory`. Inside the table: linear interpolation, with UT1−UTC interpolated as UT1−TAI so a leap second is not smeared across its day. Up to **30 days** (`kEopHoldDays`) beyond either end: the edge value is **held**. Further: `DataCoverageError`, and a `Trajectory` stops AT the limit with its state and history kept (as at the space-weather edge). **No table loaded**: `DataCoverageError` naming `ballistic.load()`, unless `EopPolicy::AssumeZero` is set explicitly (Python `ballistic.set_eop_policy('assume_zero')`), which takes UT1−UTC, polar motion and dX/dY as zero. Rows past IERS's predictions (blank x/y/UT1) are skipped and counted, not read as zeros. | Holding: one `DataCoverageWarning` per process (key `eop-outside-table`); a `Trajectory` also lists it in `warnings()`. AssumeZero: one warning (key `eop-not-loaded`). `initialize()` still sets `InitResult.eop_table_stale` when the table (including the ~1-year predictions) ends in the past. `ballistic.eop_coverage()` reports the span, the last measured day, the hold window and the skipped rows. |
| **Leap seconds** (`time::LeapSecondTable`) | 1972 onward: the table. 1961–1972: the USNO rubber-second formulas (as SOFA `iauDat`). Before 1961: `DataCoverageError` (UTC did not exist; use TT/TAI). Past the table's expiry (embedded: the IERS file's 28 June 2027) the last value is kept, which is correct unless a leap second is announced. | One `DataCoverageWarning` per process past the expiry (key `leap-seconds-expired`). `InitResult.leap_seconds_expired` / `leap_seconds_expiration_jd` report the expiry (the embedded table reports its real expiry). |
| **DragEnvironment time axis** (2D/4D density & wind tables, 2D beta tables) | **Clamps** to the first/last time slice — past the table the atmosphere freezes (over a multi-day arc a one-hour table misses a large part of the drag effect). `make_drag_environment` does not return a table: its LIVE env (`live_model.hpp`) evaluates NRLMSIS 2.1 / HWM14 at the satellite's position on the whole loaded weather file, so it has no time domain of its own, only the weather's (`weather_window()`) | Tables: a `Trajectory` records the freeze once in `warnings()` (Python `RuntimeWarning`); `DragSample.time_clamped` / `domain()` remain. Live env: a `Trajectory` stops with `DataCoverageError` at the edge of the weather (keeping state/history up to it), and warns once on entering forecast days (`measured_until()`). |
| **DragEnvironment altitude axis** | A table's density below its lowest knot (1 mm slack for round-off) **throws** (`std::out_of_range`) mid-force-evaluation; above the grid clamps/decays per profile. The live env (NRLMSIS 2.1 + HWM14) runs continuously to the ground and throws `DataCoverageError` below −1 km | Exception (can abort a propagation deep in the RK45 stack). Pass a grid that covers the arc, or `extend_density_below()` (USSA76, 0–86 km) for reentry work; stop at the ground with `propagate_until` (ground impact armed by default). |
| **Positions inside the Earth** | The force model throws `DataCoverageError` within 1000 km of the Earth's center (deep on purpose: synthetic arcs and estimator trial states run below the surface) | The trajectory has passed through the ground and is integrating toward the singular center; stop at the ground with `propagate_until`. |
| **Flow-regime drag coefficient** (`aero::FlowRegimeCd`) | On a TABULATED density (no temperature or composition) it **throws** `ConfigError`; without a velocity in `DragEnvironment::evaluate` it throws; a `MachTable` outside its Mach range throws `DataCoverageError`. The plate/cylinder continuum model (modified Newtonian) below Mach 3 is used with an `Extrapolation` diagnostic (once per process) | Never a guessed temperature or an extrapolated table. Give a `MachTable` of measured Cd for the body to cover low Mach. |
| **RK45 forced steps** | A step that fails its error test at the minimum step size is accepted with a `ForcedStep` diagnostic (strict mode: exception) | The state is outside the integrator's tolerance from there on. |
| **SpaceWeatherHistory** | **Mixed**: `at()` **throws** outside the window; `value()` **clamps** | Choose the accessor deliberately; `TimeWindow` is public. |
| **SpaceWeatherData::history** (the default drag weather) | **Throws** for days missing from the file or not measured. The `F10.7_DATA_TYPE` column decides what is measured (`OBS`/`INT` measured, `PRD`/`PRM` predicted); having 3-hourly Ap is not enough, because CelesTrak's ~45 daily forecast rows (`PRD`) have it too | Exception naming the day and the file's last measured day. `PRD` forecasts are used BY DEFAULT past the last measured day (`allow_predicted_weather`, DragSetup / Python kwarg, default true; false refuses); the env reports `uses_predicted_weather()`, the Trajectory warns once when it reaches the first forecast day, and Python `get_space_weather` / `SpaceWeatherHistory.from_loaded` issue a `RuntimeWarning`. Past the forecast it throws. `PRM` monthly rows (no Ap) are never used. `last_measured_mjd()` / Python `SpaceWeatherHistory.last_measured_day()`. |
| **SpaceWeatherData::get_conditions** (Python `get_space_weather`, legacy single-epoch path) | Never substitutes quiet defaults, an edge row, or a nearest row: its 57-hour Ap lookback needs every day it reaches, and day lookups are exact-day (a nearest-row lookup would return the previous day at exactly 00:00 UTC, where two noon stamps tie) | **Throws** `DataCoverageError` (Python `ballistic.DataCoverageError`) with nothing loaded or outside the file, and `std::out_of_range` (Python `IndexError`) when the Ap lookback reaches a day the file lacks; daily forecasts are returned with a warning (Python `RuntimeWarning`; C++ `used_predicted` out-parameter), `allow_predicted=false` refuses them. Day lookups (`get_record`) are exact-day (nullopt when the file has no row). |
| **EmpiricalAcceleration** (table and B-spline) | Holds its edge value past its arc (B-spline evaluation clamps to the knot range) | Not changed — a short hold can be intended — but a `Trajectory` that propagates more than one sample spacing past the arc records it once in `warnings()` (Python `RuntimeWarning`). Checked at `propagate()` targets and at each step's START, so the one step the interpolator takes past a query time does not trigger it. |
| **SpaceWeatherData CSV loader** (CelesTrak SW-All.csv → F10.7/Ap) | A **missing or renamed drag-critical column** would make every record quiet weather (F10.7=150, Ap=4), so it is refused | A file without the `F10.7_OBS` or `AP_AVG` column **throws** (`ballistic::Error`; nothing is loaded). A blank or unparseable value still takes a per-field default, is counted in `warnings()`, and is reported once through the diagnostics channel (`DataSkipped`; Python `DataSkippedWarning`; strict mode raises). |
| **Data download** (Python `Loader` / `ballistic.load()`) | A failed refresh of a stale cached file falls back to the cached copy | The cached copy is loaded with a warning; `offline=True` never downloads; any file can be given as a local path (`ballistic.load(space_weather="SW-All.csv", ...)`); every failure is a `RuntimeWarning` naming the consequence. |
| **DE440/DE441 ephemeris** (embedded subset 1950–2100) | **Throws** with a clear, actionable message naming the valid range | Exception — this is the model citizen; new tables should copy it. |
| **EGM2008 gravity** | A degree above the loaded model **throws** `ConfigError` (`Trajectory` checks `gravity_degree` at construction; the Clenshaw engine checks every call). Degrees 361-2190 need the NGA file through `InitConfig.egm2008_path` | Exception naming the loaded degree and the NGA file. Ocean-tide degree above the loaded file and zonal degree above J15 throw the same way; non-finite gravity throws instead of falling back to point mass. |
| **JPL ephemeris** (`JPLEphemeris`, ASCII/binary DE files) | Never evaluates an edge record outside the file or returns zero vectors for an unloaded file or unknown body | Throws (`DataCoverageError` outside the file). |
| **Trajectory/TrajectoryInterpolator** | Queries outside history auto-extend by propagation (subject to `max_propagation_time`), else `nullopt` | `std::optional` return. |

## Recommendations for new code

- Prefer the DE440 pattern (throw with an actionable message) for hard domain
  violations, and an additive flag (the `DragSample.time_clamped` pattern) when
  clamping is the intended production behavior.
- Never add a new silently-zero path. The EOP lookup is the only way to
  Earth orientation values and is guarded (static rule EOP-DIRECT).
- Unifying these policies should be done as one change, not piecemeal inside
  unrelated changes.
