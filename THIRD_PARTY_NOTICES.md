## JPL DE440 / DE421 planetary ephemerides

- `src/ephemeris/de440_coefficients.cpp` embeds a subset of the JPL DE440
  ephemeris (Sun, Earth-Moon barycenter, Moon, Jupiter barycenter;
  1950–2100), extracted from the official `de440.bsp` SPK kernel by
  `scripts/extract_de440_subset.py`; `include/ballistic/ephemeris/de440_coefficients.hpp`
  holds only the declarations. Users may load `de421.bsp` or another SPK
  kernel at run time.
- **Terms**: JPL/NAIF ephemerides are U.S. Government works, publicly
  released without use restrictions.
- **Citation**: Park, R.S., et al. (2021), "The JPL Planetary and Lunar
  Ephemerides DE440 and DE441", AJ 161:105, doi:10.3847/1538-3881/abd414.
- **Upstream**: https://naif.jpl.nasa.gov/pub/naif/generic_kernels/spk/planets/

## EGM2008 gravity model (NGA)

- `src/gravity/egm2008_coefficients.cpp` embeds the fully normalized
  spherical-harmonic coefficients to degree and order 360 of the NGA
  `EGM2008_to2190_TideFree` release;
  `include/ballistic/gravity/egm2008_coefficients.hpp` holds only the
  declarations. Degrees 361–2190 can be loaded at run time from the NGA file
  (`TrajectoryConfig::egm2008_path`), which is not part of this repository.
- **Terms**: EGM2008 is a U.S. Government (NGA) public release, free to use
  and redistribute.
- **Citation**: Pavlis, N.K., et al. (2012), "The development and evaluation
  of the Earth Gravitational Model 2008 (EGM2008)", JGR 117, B04406,
  doi:10.1029/2011JB008916.
- **Upstream**: https://earth-info.nga.mil/ (Geosciences → WGS 84 → EGM2008)

## IAU 2000A nutation series

- `include/ballistic/coordinates/nutation_coefficients.hpp` holds the
  complete IAU 2000A series (678 luni-solar and 687 planetary terms). The
  values are those published in IERS Technical Note 32 (IERS Conventions
  2003), Chapter 5, Tables 5.3a and 5.3b, from Mathews, Herring & Buffett
  (2002), JGR 107(B4), 2068, doi:10.1029/2001JB000390. The file's header
  records that the coefficients were extracted from ERFA's `eraNut00a()`
  (https://github.com/liberfa/erfa, BSD-3-Clause) and verified against
  SOFA's `iauNut00a()` (http://www.iausofa.org/).
- No ERFA or SOFA code is compiled into this library; the numerical tables
  are those of the IERS Conventions, which are published for general use
  with acknowledgement. Because the tables were extracted from ERFA's
  source, ERFA's license (BSD-3-Clause, NumFOCUS Foundation) is reproduced
  in `docs/licenses/erfa_license.txt`.

## SGP4 / SDP4

- `include/ballistic/sgp4/` is an original implementation written from the
  published mathematics: Hoots, F.R. & Roehrich, R.L. (1980), "Models for
  Propagation of NORAD Element Sets", Spacetrack Report No. 3 (a U.S.
  Government work), with the corrections documented in Vallado, D.A.,
  Crawford, P., Hujsak, R. & Kelso, T.S. (2006), "Revisiting Spacetrack
  Report #3", AIAA 2006-6753.
- No third-party SGP4 source is included or was used; in particular none of
  the source code distributed with Vallado et al. (2006) is vendored.
- The MIT-licensed `sgp4` PyPI package is a **test oracle only**
  (`tests/python/test_sgp4.py`, installed for the test run together with the
  SGP4-VER verification files it carries); it is never shipped with the
  library. A few reference positions from the published SGP4-VER output
  (`tcppver.out`, Vallado et al. 2006) for the Spacetrack Report #3 test
  object are embedded as check values in `tests/unit/test_sgp4.cpp` and
  `python/ballistic/doctor.py`.

## GeographicLib

- **Citation only.** The Clenshaw-summation gravity engine follows the
  algorithm described in Karney (2011) and the GeographicLib
  `SphericalEngine` documentation, and keeps a GeographicLib-compatible
  triangular coefficient layout. No GeographicLib code is compiled into or
  distributed with this library. GeographicLib itself is MIT-licensed.

## U.S. Standard Atmosphere 1976

- U.S. Government publication (NOAA-S/T 76-1562), public domain. The
  0–86 km model is computed from its defining constants in
  `include/ballistic/atmosphere/ussa76.hpp` (used by

## IERS conventions, Earth orientation and leap seconds

- The IERS 2010 Step-2 solid-tide tables in
  `include/ballistic/gravity/tide_arguments.hpp` are transcribed from IERS
  Technical Note 36, Tables 6.5a–c (Petit & Luzum 2010).
- `tests/data/eop/finals2000A.all` (a pinned copy of the IERS Rapid
  Service/Prediction Center `finals2000A` series) and the leap-second table
  embedded in the library derive from IERS products. Source acknowledgement: International Earth Rotation
  and Reference Systems Service (IERS), https://www.iers.org. Current copies
  are downloaded at run time by `ballistic.load()`.

## FES2004 ocean-tide coefficients

- `fes2004_Cnm-Snm.dat` (FES2004 Stokes-coefficient variations, degree
  ≤ 100; Lyard et al. 2006, LEGOS/CNES) is downloaded at run time by
  `ballistic.load()` / `Loader().load_ocean_tides()` from the IERS
  Conventions Chapter 6 site
  (https://iers-conventions.obspm.fr/content/chapter6/additional_info/tidemodels/).
  It is not part of this repository or of the wheel, because the
  distribution does not state redistribution terms for this third-party
  model. Only the evaluation code
  (`include/ballistic/gravity/ocean_tides.hpp`, IERS 2010 eq. 6.15) is
  original to this library.

## Space weather indices (CelesTrak)

- `tests/data/weather/SW-All.csv` is a copy of CelesTrak's space-weather
  file (daily F10.7, Kp/Ap and related indices from 1957 on), used by the
  drag tests so that they do not depend on the network. Current copies are
  downloaded at run time by `ballistic.load()` /
  `Loader().space_weather()`.
- Source: CelesTrak, https://celestrak.org/SpaceData/, which compiles the
  geomagnetic indices (GFZ Potsdam) and the 10.7 cm solar flux (NRC Canada /
  NOAA). Terms as published by CelesTrak and the index providers.
